## On the machine, in this order. STOP at the first one that misbehaves.
#   t0_identical  byte-identical      -> proves the card/transfer path only
#   t1_tempo      2-byte field        -> confirms the 1/128 BPM scale
#   t2_step       1 bit               -> confirms step bit order and origin
#   t3_sample     1 field             -> confirms the sample-number field
#   t5_motion     one motion slot     -> confirms motion writes
#   t4_commit     a whole new sample  -> confirms the entire commit path
#   t6_song       a 4-position song   -> confirms the song chain WRITES correctly
#   t7_ccprobe    CC 95..127 in rows  -> names the CC-assign rows (see below)
#
# The generator prints exactly what to look at for each. Write down what you
# actually see, especially for anything that differs.

## HIGHEST VALUE: name the MIDI CC assign rows. Blocks a requested feature.
#
# The CC table is located (global block +23..+55, 33 rows) and is editable, but
# WHICH KNOB each row drives is unknown: every bank carries the identical
# factory table, so the order is not in the data anywhere. Until it is named,
# remapping a controller means editing rows blind.
#
#   1. Load t7_ccprobe. It has written CC 95..127 into rows 1..33.
#   2. Global > SHIFT + step key 15 (MIDIUtil) > dial to CCAsin > key 15.
#   3. Dial through EVERY knob. Write the knob name against the CC number
#      shown. Row N carries CC 94+N, so CC 95 = row 1 ... CC 127 = row 33.
#   4. Load a t0 bank afterwards to put the factory assignments back.
#
# One pass names the whole table, because every row carries a distinct ordered
# number. A screenshot of SawLoop's MIDI CC page would do the same job without
# taking the machine out.

## Confirm the song chain, both directions

# READ direction is already settled: Chronic-Interactive-3.esx decoded to

#
# WRITE direction is what t6_song tests: it builds song 04 named HWTEST with
# the chain A.02 -> A.01 -> A.04 -> A.06. Play it. Reading a format correctly
# does not prove writing it correctly, and this is the cheap way to find out.
